## 构建流程的含义

GitHub Actions 默认只编译和打包。绿色构建仅表示编译打包成功，不能表示硬件维修或 UI 功能全部验证通过。模拟自检只有在手动工作流选择后才会执行。

可在 Windows 上手动运行 `scripts/test.ps1`；输出和模拟样本留在被 Git 忽略的 `artifacts/tests/`。模拟自检不替代不同品牌、驱动、权限和显示缩放环境的实测。
