# 使用说明

## 基本流程

解压到可写位置，打开主程序，等待只读扫描完成。先查看概览、设备异常和检测范围，再在维修引导中选择问题。扫描信息只能说明本次 Windows 提供的数据，未发现异常不等于硬件完全健康。

声音问题先确认输出设备并试听；再按需恢复音频服务或重启指定声卡。程序会记录修复前后状态，真正发声仍需用户确认。网络问题先查看网卡、地址和分层诊断，必要时重启选中的网卡。远程维修时重启网络设备可能中断远程连接。

修复不是批量重启所有硬件。程序保护系统关键设备；具体设备是否允许操作由设备类别和实例 ID 策略决定。驱动可能仍要求整机重启，程序不会自动重启整机。

## 压力测试与温度

压力测试手动启动，界面时长为 30–180 秒，可停止。内存分配受可用内存限制，测试子进程有时间和父进程存活约束。取消、未完成与检测出计算错误的结果不会显示为通过。

没有温度自动保护或 GPU / 磁盘压力负载；测试通过只代表这段时间内完成的运算与读写校验。若温度异常或电脑明显不稳定，请停止负载。

GPU 温度依赖 WDDM 驱动提供数据，不保证每种显卡都支持。CPU 使用率不是 CPU 温度，ACPI 系统温区也不是已确认的 CPU 核心温度。实时监控需手动开启，约每 2 秒采样、保留最近 5 分钟，不写入历史曲线报告。

## 历史报告

“保存当前报告”创建独立快照；刷新列表后选择查看，导入 JSON 需明确选择文件。导入报告可能来自另一台电脑。历史报告保留原扫描时间，不替代当前状态；列表最多显示最近写入的 200 个报告。

顶部的隐藏身份选项同样适用于历史保存、导入和导出，但只处理已知账户和电脑名。报告可能仍含网络地址、设备标识和备注。数据存于 `Data/<电脑与账户标识>/Reports`。损坏或不支持的文件会提示，不会自动删除。

## 独立 Edge 资料备份

只对自己的资料或获得明确授权的资料操作。在独立备份页阅读范围、保存工作、勾选同意，并在确认框中确认。备份不会随扫描、引导、压力测试或启动自动执行。

来源是当前运行账户的 `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default`，与运行程序的身份绑定，不会根据扫描到的其他用户名拼接目录。

目标是程序目录下 `Edge/` 的独立时间戳目录。预检可用空间、文件大小和写权限后，关闭当前账户、当前会话的 Edge；等待后仍未退出的进程会被强制结束。此时未保存内容可能丢失。备份过程中不要重新打开 Edge。

支持停止、进度、复制后回读 SHA-256 校验。取消或失败保留部分文件及结果记录；请查看最终状态，不要把部分备份当作完整备份。当前未保存可供后续重新验证的逐文件校验清单。

`Default` 包含敏感的密码数据库和登录会话，但不包含其他配置文件及上级 `Local State` 文件。程序不做解密或账号恢复。加密文件不代表备份可以随意公开，跨电脑恢复也不保证成功。

## 更新与卸载

先结束测试或备份并关闭程序，再覆盖程序和随附文档。保留自己的 `Data/` 和 `Edge/`，不要将其上传到 GitHub。程序无需安装系统服务；如要删除便携目录，先自行保存需要的报告和备份。

小窗口支持滚动；部分表格和内容可能需要横向或纵向滚动才能看全。v1.7.1 尚未完成实际小屏、高 DPI 和长确认框的界面验收。
