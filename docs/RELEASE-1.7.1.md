# PurpleCare 1.7.1 — 首次公开预发布

紫芯电脑助手现有便携版的源码基线，支持 Windows 10 2004+ / Windows 11 x64，需要 .NET Framework 4.8。

## 下载

下载 `PurpleCare-1.7.1-windows-x64.zip`，完整解压，打开 `紫芯电脑助手.exe`。同名 `.sha256` 附件用于核对 ZIP。兼容入口 `紫芯电脑助手-v1.4.exe` 会打开同目录的新版程序。

## 本次内容

- 本地硬件扫描、指定声音 / 网络设备修复、手动压力测试和 GPU 温度读取。
- 维修引导、修复对照、历史报告中心和 HTML / JSON 导出。
- 独立、需明确确认的 Edge Default 资料备份入口。
- 小屏布局和确认框滚动、旧入口跳转新版。
- MIT 项目代码、独立照片许可说明、构建与打包脚本和开发文档。

## 预发布状态

编译和打包不代表维修功能全部验证通过。本版本尚未完成实际 UI、小屏 / 高 DPI 和长确认框验收，因此标记为预发布。此前模拟自检记录为 109 项通过，本次公开整理未重新运行功能测试。没有完成架构重构。

程序没有代码签名，不会保证修复所有硬件故障。CPU 核心温度、GPU / 磁盘压力测试和温度自动停止尚未支持。备份会关闭当前账户的 Edge，须先保存工作；程序不会随启动或扫描自动备份。

发布附件不包含本机报告、日志或浏览器资料。自行运行后的 `Data/` 和 `Edge/` 可能含敏感信息，不要上传到 Issue 或公开仓库。
