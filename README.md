# 紫芯 · 电脑助手 / PurpleCare

面向 Windows 10 / 11 的便携式硬件诊断与维修辅助工具。C#、WPF、.NET Framework 4.8，支持从 U 盘运行，界面采用赛车照片主题。

**当前版本：1.7.1，预发布。** 小屏布局与确认框改动尚未完成实际界面验收。它能读取系统状态、辅助排查和重启部分设备，不能保证检测出全部硬件故障，也不能修复物理损坏。

## 下载与运行

1. 在 [Releases](https://github.com/dreamdavidmit-glitch/PurpleCare/releases) 下载 Windows x64 ZIP，完整解压到可写目录或 U 盘。
2. 打开 `紫芯电脑助手.exe`。不要在压缩包内直接运行。
3. 程序启动后进行只读扫描；设备修复需主动确认，并按需请求管理员权限。

支持 Windows 10 2004+ / Windows 11 x64，需 .NET Framework 4.8。暂不支持 WinPE、WEPE 或原生 ARM64。U 盘盘符可以变化，路径跟随程序目录。兼容入口 `紫芯电脑助手-v1.4.exe` 只转到同目录新版主程序。

发布包未做代码签名。请从本仓库下载，并使用发布附件中的 SHA-256 核对 ZIP；不要为运行本软件关闭系统安全保护。

## 功能与边界

| 功能 | 当前行为 |
| --- | --- |
| 电脑识别与扫描 | 读取电脑名、当前账户、品牌型号、设备、驱动及部分系统健康信号 |
| 温度与实时监控 | 显示驱动可提供的 GPU 温度、系统温区、CPU / 内存使用率；未读到的数据保持未知 |
| 声音修复 | 测试指定声音输出，重启音频服务或所选声卡，并记录用户是否实际听到声音 |
| 网络修复 | 单独重启所选网卡；手动执行链路、网关、DNS、HTTPS 分层诊断 |
| 压力测试 | 有时限的 CPU 校验和内存模式读写、停止按钮、结果与曲线 |
| 维修引导 | 声音、网络、卡顿问题的分步检查和用户观察记录 |
| 历史报告 | 保存、导入及导出 HTML / JSON；历史记录不覆盖当前扫描 |
| 独立资料备份 | 当前账户 Edge 的 `Default` 目录，手动勾选并再次确认后才执行，支持进度与 SHA-256 回读校验 |

CPU 核心温度尚未接入；ACPI 温区不会标为 CPU 温度。压力测试不含 GPU / 磁盘负载，也没有基于温度的自动停止。重启网卡会中断连接；CPU、内存、系统盘和存储控制器不支持单独重启。详见 [使用说明与限制](docs/USAGE.md)。

## 数据与隐私

- 报告、记录和测试结果写在程序旁 `Data/`，按电脑和账户隔离。U 盘运行时这些信息也留在 U 盘上。
- 手动浏览器备份写在程序旁 `Edge/`，可能含密码数据库、Cookie 和登录会话。只复制、不解密、不上传；复制 `Default` 不等于完整迁移，跨电脑恢复登录状态不保证可用。
- 启动、扫描、压力测试都不会自动触发浏览器备份。备份时会关闭当前账户、当前会话的 Edge，请先保存工作。
- 没有内置报告上传或遥测服务。主动网络诊断会向目标域名发送 DNS / HTTPS 请求并探测网关，使用系统路由；HTTPS 探测不使用系统 HTTP 代理。
- 导出默认隐藏已知账户和电脑名，仍可能包含 IP、设备标识或自由备注。提交 Issue 前自行审阅，**不要上传 `Data/`、`Edge/`、完整个人报告或浏览器资料**。

## 从源码构建

在 Windows PowerShell 5.1 或 PowerShell 7 中运行：

```powershell
.\scripts\build.ps1
```

输出到 `artifacts/build/`。脚本使用 Windows 自带的 .NET Framework 64 位 C# 编译器，不需要 NuGet、Node.js 或 Visual Studio。所需编译器和 WPF 引用必须已安装。

生成不含本机数据的便携包：

```powershell
.\scripts\package.ps1
```

生成的 ZIP、SHA-256 文件放在 `dist/`。脚本只收集指定程序、文档和许可文件，不复制运行数据。默认构建和打包均不启动应用、不运行功能测试。

需要时手动运行现有模拟自检：

```powershell
.\scripts\test.ps1
```

自检会在 `artifacts/tests/` 生成模拟文件，不重启真实设备、不运行浏览器备份。已知验证范围见 [验证记录](docs/VALIDATION.md)。GitHub Actions 默认只编译打包，自检仅在手动勾选后运行。
